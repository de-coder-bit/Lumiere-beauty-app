## 📋 Features

### 🏠 Customer Features
| Feature | Description |
|---------|-------------|
| 🤖 **AI Stylist** | Interactive chat interface for personalized beauty recommendations |
| 💈 **Salon Discovery** | Grid & map view to find premium salons near you |
| ⭐ **Salon Profiles** | Detailed salon info with services, stylists, and reviews |
| 📅 **Booking System** | Seamless appointment booking with date/time picker |
| 👤 **Customer Dashboard** | Track bookings, favorites, and AI history |
| 🔔 **Smart Notifications** | Real-time updates for booking confirmations |

### 👑 Salon Owner Features
| Feature | Description |
|---------|-------------|
| 📊 **Business Dashboard** | Real-time analytics and revenue tracking |
| 👥 **Staff Management** | Manage stylists and their schedules |
| 💰 **Payout Management** | Track earnings and payment history |
| ⭐ **Review Management** | Respond to customer reviews |
| 📈 **Performance Metrics** | Monthly revenue, appointment trends, customer retention |

### 🎨 UI/UX Highlights
- ✨ **Luxury Aesthetic** - Rose gold & warm neutral color palette
- 📱 **Fully Responsive** - Works on desktop, tablet, and mobile
- 🎭 **Glassmorphism Effects** - Modern blur effects and shadows
- ⚡ **Smooth Animations** - Hover effects and transition animations
- 🔍 **Advanced Filters** - Search by location, price, service type
